# 《古代监控实录》配方

把历史名场面、寓言和民间传说重新演成一段**固定机位的监控录像**：高位俯拍、广角畸变、画质偏低、黑白（夜里是红外），屏幕上走着「公历日期 + 年号农历月 + 时辰」的时间码。竖屏版上方是标题，中间是监控画面，下方是两行钩子文案和出处注释。

笑点在「现代监控拍到了古人」，所以两件事必须对：**动作和原文一致**，**时间码的年代信息正确**。下面的关卡就是为这两件事设的，每一条都来自翻过的车。

| 文件 | 用途 |
|---|---|
| [`plate.md`](plate.md) | 首帧（监控空镜/定位画面）怎么写、怎么出图、用前查什么 |
| [`review_prompt.md`](review_prompt.md) | 渲染前交给另一个大模型的文字审校提示词 |
| `cctv_post.py` | 后期：监控质感、屏显时间码、闪烁 REC、静电雪花转场、横屏 master 和竖屏 vertical |
| [`episodes/smg/`](episodes/smg/README.md) | 司马光砸瓮：首帧、3 条提示词、seed、`episode.json` |
| [`episodes/wenji/`](episodes/wenji/README.md) | 闻鸡起舞：首帧、2 条提示词、seed、`episode.json`（红外夜景） |

## 流程

```
① 原文锁定（动作链）→ ② 首帧 → ③ 逐镜提示词 → ④ 文字审校 → ⑤ 出片（i2v，10–12 s）
→ ⑥ take_gate + 联系表看片验收 → ⑦ cctv_post.py → ⑧ 竖屏安全区检查，发布（带 AI 标识）
```

## 关卡 1：原文锁定（写任何提示词之前）

每集先把原文引文放进 `note`，把关键动作链写成 **动词 → 对象 → 打在哪 → 结果**：

> 司马光砸瓮 = 光**持**石（双手握）→ **击**瓮**侧壁下部** → 瓮**破**出一个大口（一大块瓮壁脱落，瓮仍立着）→ 水**迸**，儿随水从破口**一起冲出** → 儿得活

- 按动词的全部力度理解：「破之」是砸开一个大口，不是一个小孔。结果要直接由动作导致：只砸出一道细水柱、孩子自己从瓮口爬出来，不对。
- 提示词要把链条的每一环都写出来：怎么握、打在哪、什么保持完好、结果在哪里出现。动词含糊（「smash the vat」）就会让模型自己编物理：第一版司马光把石头扔进了瓮里，整只瓮炸开。
- 同时核对：**在场人数**（鸿门宴是刘邦独骑，樊哙等四人持剑盾步行）、**时段**（鸿门宴是白天，第一版做成了夜景）、**道具归属**（羽扇只属于诸葛亮）。

### 1b 表演力度

H3 默认把接触演得很轻（「轻轻磕碰的样子，太轻松」）。每个关键动作写成 **蓄力 → 接触 → 反作用 → 可见后果 → 身体反应**：

> 司马光：双手把石头举过头顶、手臂发抖 → 像劈柴一样用全身重量砸下 → 一声脆响、瓮一震、水泼出来 → 石头弹飞、人摔坐在地 → 出现裂纹 → 爬起来再砸

- 七岁孩子抱头那么大的石头要显得吃力：膝盖发软、踉跄、砸好几下，前几下砸不开。
- 旁观者的反应留一拍：先**愣住约 2 s**，再跑（落瓮后众儿先愣住，再「皆弃去」）。
- 10 s 最多 4–5 拍；动作链更长就拆成**同一机位**的 2–3 个镜头，用上一镜的末帧接力。

### 1c 一集一个固定机位

多机位、切到关键动作的近景机位，看起来就不像监控了。规则：

- 每集一个机位：**高位、俯拍、广角**（屋檐角、柱子、墙角）。人在画面里很小，没有人看镜头、知道镜头存在，什么都不是摆拍。关键动作在远景里要看得清，但永远不给特写。
- **不在机位之间切换**。连续的动作用上一镜末帧接力（接缝看不出来）；时间跳跃用同一机位、同一构图，时间码跳一下，中间插一下雪花 / NO SIGNAL。一集里所有镜头的 `cam` 都一样。
- 机位要选在关键动作发生在**画面中部、中景距离**的位置。动作离镜头太远，H3 会自己推过去（鸿门宴有一镜两个 seed 都在第 3 s 后朝茅厕推近）。
- 要的质感：略低的分辨率、轻微噪点和压缩块、桶形畸变、偶尔掉帧，夜里是红外黑白；不要电影光、电影构图和运镜。

### 1d `subject_definitions` 只写 t=0 就在画面里的

H3 会把定义过的每个主体都放进开头几帧。整集共用一份定义块的后果：守株待兔第二镜树桩边凭空多出一只兔子（笑点没了）；程门立雪第一镜程颐站在自己门外；鸿门宴里刘邦还没出帐，卫兵已经站在帐前。

- 每个镜头单独写定义；后进场的人只在他的节拍里写（「at 8 s a servant boy opens the cottage door」）。
- **每张首帧和关键帧用之前都要看**：人数、多出来的动物和道具、时段。

## 关卡 2：文字审校（渲染之前）

把 `episode.json`、全部提示词和 [`review_prompt.md`](review_prompt.md) 交给另一个文字能力强的大模型，让它按原典逐镜审：动作逻辑、人物和道具、时间戳、脚注引文、场景、季节和昼夜、表演力度。审出来的「高 / 中」问题全部改掉再提交渲染。

审校只看文字，不要让它判断图片和成片：图片和成片要自己看（关卡 3）。

## 关卡 3：看片验收（发布之前）

每条镜头都出一张 4×3 的联系表（`tools/contact_sheet.sh`，每秒 1.2 帧），**逐帧对照关卡 1 的动作链**，确认每一环都按顺序出现。任何一环断了就重渲（出两个 seed），不发布。同时检查：

- 有没有多出来的人、换了手的道具、服装漂移；
- 机位有没有动：`take_gate` 报 ZOOM 时，在三个时间点抽帧，对比背景地标的大小；
- 有没有模型自己的切镜：`take_gate` 报出的 `cuts`；
- 有没有冒出人声：有台词的镜头用 `--profile dialogue --lines` 核对；不该有台词的镜头，用 `--profile dialogue` 不带 `--lines` 跑一遍，听到人声会报 EXTRA。

## 时间戳规则

- **格式**：第一行 `公历日期  年号+农历月`，第二行 `时:分:秒  X时`。时辰按小时：子 23–1、丑 1–3、寅 3–5……亥 21–23。**不写星期**（古代没有星期）。时钟数字保留，现代屏显本身就是笑点，但年代信息必须对。
- **年和月取原文。** 日子没有记载时，取该月的中气日，保证农历月对：正月雨水、二月春分、三月谷雨、四月小满、五月夏至、六月大暑、七月处暑、八月秋分、九月霜降、十月小雪、十一月冬至、十二月大寒。并在 `note` 里写「日期为演绎」。
- **历法**：1582 年以前用儒略历（冬至约等于「格里历日期 −13 天 + 0.0078 天 ×（2000 − 年份）」再按这个关系换算），清代用格里历。确切记载的日子优先（康熙驾崩：1722-12-20 戌刻）。
- **太初改历（公元前 104 年）以前不适用中气规则**：秦和汉初用颛顼历，岁首在十月，闰月放在年底（后九月），某个月可能根本不含中气。用同一年有干支日期的记载来定月份，比如《汉书》元朔三年「六月庚午」= 前 126 年 6 月 25 日，可以推出九月是 9 月 21 日到 10 月 19 日，霜降（10 月 26 日）不在九月里，只能取月内的节（寒露，10 月 12 日）。也可以用本纪、五行志的日食记载或秦简历日来锚定，再数真实的朔日。作者按中气规则算李广那一集时就错过一次：算出来的「九月」那天其实已经过了九月。
- **时段取原文**：旦日、中夜、戌刻、昼寝……
- **寓言和传说**加【寓言】/【民间传说】标签，并在 `note` 里写清哪些是虚构的，或者这个传说为什么站不住（比如「传位于四阿哥」：诏书要称「皇十四子」，改一个字成了「皇于四子」，不通；遗诏还是满汉合璧的）。
- **一集里的镜头时间只能往前走**；时间跳跃靠时间码 + 雪花转场表现。

## 提示词的固定写法

结构化英文六段式（见 [docs/03-prompt-guide.md](../../docs/03-prompt-guide.md)），i2v，1344×768，每条 10–12 s。每条都带上这几类条款（样例里的原文可以直接复用）：

- 固定机位：`Fixed wall-mounted security camera, high angle, wide lens, locked off, no camera movement, nobody looks at the camera. The camera stays completely static for the whole clip: no pan, no tilt, no zoom, no push-in, no shake, no cuts, no change of angle; ...`
- 监控质感：`Real CCTV surveillance footage: flat dull ambient light, no cinematic lighting, no dramatic composition. The people do not know the camera is there ...`
- 不加人、不出字：`No people other than those described appear. No writing or text appears anywhere in the picture.`
- 声音：`thin tinny surveillance microphone ambience, faint background hiss, ... No music, no clear speech, no subtitles, no on-screen text.`

接力只用于连续的状态（马已经走了、雪越积越厚、船装满了），最多连续 2 次。

## 台词：要么给原句，要么全静默

让人物「说话」却不给台词（「书童说先生不在」「招手低语」），H3 会编出听不懂的伪中文（识别出来是「申堆来，入拜」「来来来……捡来捡来」）。summary 里的间接引语也一样。二选一：

1. **给原句**：台词用引号写在它的节拍里，只说一次；出片后用 `take_gate.py --profile dialogue --lines "…"` 核对；后期在 `episode.json` 里给这条镜头加 `keep_audio`、`subs`（屏幕对白字幕）和 `gate`（只保留台词时段的声音，去掉模型在台词前后重复的话和伪中文）。
2. **全静默**：只写手势（指、摇头、挥手），加 `everyone stays silent, nobody talks`。已经冒出人声的整集可以设 `"mute_src": true`，只留监控底噪。

引号以外绝对不要出现中文（要强调「十」就写 the word for fourteen），台词里避免「——」。H3 偶尔也会把引号里的台词烧成字幕：每条对白镜头都看联系表的下三分之一，有字就不用。

## 已知翻车

| 现象 | 做法 |
|---|---|
| 多出一个人（刘关张旁边多了个孩子） | 写死人数 + 「nobody else」 |
| 道具换手（关羽拿着羽扇） | 写明每件道具属于谁，其他人 `hands empty` |
| 离镜头近的人只拍到背影 | 首帧里把人物放在中景距离 |
| 破坏动词演成爆炸 | 写明什么保持完好、破口在哪 |
| 写了固定机位还是推到特写（司马光有个 seed 就推了） | 动作再对也不要这条 |
| 模型自己切镜（司马光第二镜某个 seed 在 2.83 s 切了一刀）或推近 | 固定机位的格式里不要这条；切点之前那一段能用就只用那一段，不要把变了的构图当成另一个机位 |
| 冒出伪中文 | 见上一节 |
| 烧出字幕 | 引号外不写中文；逐条看下三分之一 |
| 一条拍得好，后半段出了问题 | 从中途接力：抽出第 t 秒的帧，从它渲下一镜，前一条加 `"trim": [0, t]`，接缝看不出来 |
| 一条里的雪积不起来 | 用接力镜头 + 更大的时间跳跃 |
| 时间噪点让 x264 码率爆炸（28 s 的 master 在 crf 19 下 282 MB） | `cctv_post.py` 已经给 master 和 vertical 加了码率上限 |

## 后期：`cctv_post.py`

```bash
python3 recipes/cctv/cctv_post.py recipes/cctv/episodes/smg/episode.json \
    --shots outputs/smg/shots --out outputs/smg [--ffmpeg /path/to/ffmpeg] [--font NotoSansCJKsc-Bold.otf]
```

- 读 `episode.json`，从 `--shots` 目录取 `<镜头名>.mp4`，输出 `<out>/master.mp4`（1920×1080）和 `<out>/vertical.mp4`（1080×1920）。
- 需要带 `drawtext`（libfreetype）和 `libx264` 的 ffmpeg，用 `--ffmpeg` 指定。
- 字体：`--font` 是简体中文字体文件，`--mono-font` 是时间码用的等宽字体；不传时用 `fc-list` 自动找。`.ttc` 只会用第 0 个字体，见 [docs/01-install.md](../../docs/01-install.md)。
- 中间文件和完整的 ffmpeg 命令（`run.sh`）在 `<out>/_work/`；`--dry-run` 只生成 `run.sh` 不执行。

### `episode.json` 格式

一个文件可以放多集，用 `--ep` 选；只有一集时不用。

```json
{"smg": {
  "no": "01",
  "title": "司马光砸缸",
  "tag": "史载",
  "cam": "CAM-02 司马府·后院",
  "caption": ["监控拍下：一名儿童落瓮，众儿皆跑，", "只有七岁的他留了下来……"],
  "note": "据《宋史·司马光传》：……月份、日期为演绎。",
  "ir": false,
  "shots": [["smg_c1_s31", "1025-04-15", "天圣三年三月", 51785, {"cam": "CAM-02 司马府·后院"}],
            ["smg_c2_s31", "1025-04-15", "天圣三年三月", 51795, {"cam": "CAM-02 司马府·后院", "join": "relay"}]]
}}
```

| 字段 | 含义 |
|---|---|
| `no` | 集号，只作记录（竖屏标题不显示集号） |
| `title` | 片名，竖屏版标题下面那一行（超过 13 个字会自动缩小字号） |
| `tag` | 竖屏版注释前的【标签】：史载 / 寓言 / 民间传说 |
| `cam` | 默认机位名，显示在左下角；`CAM-02` 里的数字同时显示为右下角的 `CH02` |
| `caption` | 竖屏版画面下方的两行钩子文案 |
| `note` | 出处和说明，竖屏版按每行 25 字换行，最多 7 行 |
| `ir` | `true` = 红外夜视（黑白 + 泛光 + 右上角 `IR`） |
| `bw` | 默认 `true`（黑白）；`false` = 保留褪色的彩色 |
| `crop` | 可选，`"w:h:x:y"`（原片像素），每条镜头都裁同一个窗口，比如裁掉模型烧进去的字 |
| `mute_src` | `true` = 所有镜头去掉原声，只留监控底噪（`keep_audio` 的镜头除外） |
| `shots` | 每条镜头：`[镜头名, 公历日期, 年号+农历月, s0, {选项}]`，`s0` 是这条镜头开始时的时钟秒数（从午夜算） |

镜头选项：

| 选项 | 含义 |
|---|---|
| `cam` | 这条镜头的机位名（一集里应当都一样） |
| `join` | 和上一条怎么接：`"relay"` 直接接（连续动作），默认 `"static"` 插 0.8 s 转场（0.3 s 雪花 + 0.5 s NO SIGNAL） |
| `trim` | `[开始秒, 结束秒]`，只用这一段 |
| `keep_audio` | `true` = 有真实台词的镜头，保留更宽的人声频段（200–5200 Hz）；`false` = 这条静音 |
| `subs` | `[[t0, t1, "说话人：台词"], ...]`，屏幕对白字幕，时间是这条原片里的秒数 |
| `gate` | `[[t0, t1], ...]`，只在这些时段保留原声，时间是这条原片里的秒数 |

接力镜头的 `s0` 接着上一条往后数（上一条 10 s，下一条的 `s0` 就加 10），时钟才连续。时间跳跃就让 `s0` 跳，并用 `"join": "static"`。

### 它做了什么

- **画面**：先压成廉价录像机的样子（12 fps、704×400、380 kb/s 的低码率、随机丢约 3% 的帧）→ 放大到 1920×1080（双线性，发虚）→ 桶形畸变 → 黑白并带缓慢的曝光呼吸（`ir` 时是高反差红外加泛光，`bw: false` 时是褪色彩色）→ 锐化 → 时间噪点 → 暗角。
- **屏显**：左上两行时间码（日期 + 年号月 / 时钟 + 时辰，时钟随画面走），右上闪烁的红点 REC，左下机位名，右下 `CHnn`。屏显向内缩进约 11%，竖屏在长屏手机上被裁边时也看得见。
- **声音**：带通 280–3600 Hz + 压缩 + 粉红噪声底噪；`keep_audio` 的镜头用 200–5200 Hz，保住 s/sh/x 这些音的清晰度。
- **转场**：`static` 接法插 0.3 s 雪花加白噪声，再接 0.5 s 黑底 NO SIGNAL（静音）。
- **竖屏**：深色底，上方「古代监控实录」和片名，「▼ 原始监控画面」，中间是满宽的监控画面（1080×608），下方两行钩子文案、【标签】、出处注释，最下方「内容由AI生成 · 纯属虚构演绎」。
- **码率上限**：时间噪点会让 x264 码率爆炸，master 限 6 Mb/s，vertical 限 5 Mb/s。

### 竖屏安全区

长屏手机（19.5:9、20:9）全屏播放 9:16 视频时会撑满高度，左右各裁掉约 9–10%（96–108 px）。所以竖屏版的所有文字都在 x = 110..970（860 px）以内：文案字号按 860 px 自动缩放，注释每行 25 字。监控画面是满宽的，被裁掉的只是暗角边缘。发布前做一次裁切模拟，两侧各画一条 96 px 的红条，看有没有字被盖住：

```bash
ffmpeg -ss 12 -i outputs/smg/vertical.mp4 -frames:v 1 \
  -vf "drawbox=x=0:y=0:w=96:h=ih:color=red@0.5:t=fill,drawbox=x=iw-96:y=0:w=96:h=ih:color=red@0.5:t=fill" safe_check.png
```

## 常用命令

```bash
# 接力：取上一条的末帧当下一条的首帧
ffmpeg -sseof -0.15 -i shots/a.mp4 -frames:v 1 -update 1 shots/a_last.png
# 从中途接力：取第 7.5 秒的帧，前一条在 episode.json 里加 "trim": [0, 7.5]
ffmpeg -ss 7.5 -i shots/a.mp4 -frames:v 1 shots/a_at7.5.png
# 联系表
bash tools/contact_sheet.sh shots/a.mp4
# 单条质检（不该有人声的镜头也可以用 dialogue 档查有没有冒出人声）
python3 tools/take_gate.py shots/a.mp4
python3 tools/take_gate.py shots/a.mp4 --profile dialogue
```

## 已经验证过的史实

审校时可以对照，每一行都纠正过一次真实的错误：

| 集 | 原文 / 出处 | 正确演法 | 曾经的错误 |
|---|---|---|---|
| 司马光砸瓮 | 《宋史·司马光传》「一儿登瓮，足跌没水中，众皆弃去，光持石击瓮破之，水迸，儿得活」 | 瓮（大腹小口）不是缸；脚先滑落没顶；众儿先愣住再跑；连砸几下，前几下不破；击侧壁下部，一大块瓮壁崩开，水和孩子一起冲出；首帧是春景就写三月 | 抛石入瓮、整瓮炸开；只砸出细水柱；一下就破；春景首帧配五月 |
| 闻鸡起舞 | 《晋书·祖逖传》「共被同寝，中夜闻荒鸡鸣，蹴琨觉曰：『此非恶声也。』因起舞」 | 中夜（子时）；用脚把刘琨踢醒；元康六年前后（刘琨约二十六岁） | 元康元年（刘琨才二十一） |
| 鸿门宴 | 《史记·项羽本纪》 | 白天；刘邦脱身独骑，樊哙等四人持剑盾步行；张良一直在帐外等，之后才入帐献礼 | 做成夜景；四人从帐中追出；张良当场回帐；一镜塞了十个动作 |
| 三顾茅庐 | 《三国志》「凡三往，乃见」；细节出自《三国演义》第 37–38 回 | 羽扇只属于诸葛亮；三次拜访各发生了什么按回目来 | 关羽拿着羽扇 |
| 守株待兔 | 《韩非子·五蠹》 | 道具是耒（脚踩入土的木叉），株是树桩；之后兔子再也没来，田荒了 | 用了锄头；兔子从打盹的他身边溜过（寓意变成了「偷懒错过」） |
| 曹冲称象 | 《三国志·邓哀王冲传》「置象大船之上，而刻其水痕所至，称物以载之，则校可知矣」 | 象上船 → 刻水痕 → 象下船 → 石头逐筐过秤再装船 → 船沉到刻痕 → 合计 | 少了「称物」这一步；年份错 |
| 程门立雪 | 《宋史·杨时传》「颐偶瞑坐，时与游酢侍立不去，颐既觉，则门外雪深一尺矣」 | 屋内：程颐闭目端坐（不是睡觉），两名学生侍立在旁；门外下雪 | 两个年轻书生站在门外雪地里堆成了雪人 |
| 传位于四阿哥 | 民间传说 | 标【民间传说】；拆穿要有力：须称「皇十四子」，改字不通；遗诏满汉合璧 | 只用「於/于」一条，论据太弱 |
