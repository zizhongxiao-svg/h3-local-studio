# 04 制作流程

总原则：**先把图定死，再动视频。** 改一张图大约 1 分钟；改一条视频要重渲几分钟，还常常连累相邻镜头（服装、位置、光线都得跟着对）。所以视频只用来让已经审过的静帧动起来，故事和画面的问题都在静帧阶段解决。

十步，每步都有关卡。前一步没过，不进下一步。

```
① 故事/设定 → ② 人物 → ③ 场景与道具 → ④ 分镜 + 状态板 → ⑤ 关键帧 → ⑥ 动画样片
→ ⑦ 出片 → ⑧ 质检 → ⑨ 剪辑/配乐/字幕 → ⑩ 发布
```

## ① 故事和设定

先用文字把故事定死，后面每一步只是执行。

**系列设定（bible）**，第一集之前写一次：

```
FIT       这个故事用到本地模型的哪些长处，主要爽点落在长处还是短处
LOGLINE   一句话：谁想要什么，什么挡着他，哪里不寻常
HERO      外在目标 · 内在需要 · 伤口 · 一个看得见的小习惯
OPPONENT  和主角冲突的目标 · 他为什么觉得自己对
MECHANIC  规则（能力、契约、倒计时）、它的代价、唯一的例外，分别在哪一集哪一拍教给观众
WORLD     2–4 个反复出现的场景（每个只做一张场景图，每集复用）· 3–6 个反复出现的道具
ARC       每集一行：这一集改变了什么 · 观众要的爽点 · 结尾钩子 · 用到的场景
```

**单集合同**，每集的表头：这一集观众问的那个问题（QUESTION）、0–3 s 的钩子（HOOK，画面里要有正在发生的麻烦和人，第一句台词 ≤ 1 s）、转折（TURN）、兑现（PAYOFF，要在画面上发生）、最后 3 s 的新问题（END HOOK）。

**故事关**：把设定、单集合同和分拍表交给另一个模型审，只给材料，不给你的想法，让它先回答问题再打分：

1. 用一句话复述这一集：有主语、有指向某人的动作、有结果吗？复述不出冲突，不过。
2. 主角做了哪些选择（不是发生在她身上的事）？每 20 s 不到一个选择，不过。
3. 前 3 s 有没有正在发生的麻烦和人脸/人体？空景、片名卡、慢推建筑，不过。
4. 转折有没有前面埋过的伏笔，对观众是不是意外？两样缺一样，不过。
5. 最后一拍是新问题，还是旧问题的答案？
6. 爽点是在画面上演出来的，还是靠一句台词交代的？
7. 每 20–30 s 有一个情绪点吗？相邻两个是不是同一种情绪？
8. 需要模型短处的拍子（两人重接触、群戏、打斗编排）有几个？超过一个，或者没写替代拍法，不过。

前几条不过就退回改故事。故事不过关，后面的画面工艺补不回来。

## ② 人物：脸型库方法

方法来自远见明察的公开文章《GPT Image 2.5 做 Seedance 2.5 角色脸型库》（2026-11）。静帧用什么图像模型都行，比如 GPT Image（官方未在中国大陆提供服务）、即梦，或在本地跑开源的 Qwen-Image。下面是按这个方法改写的做法。

**为什么 AI 人物都长一个样**：模型默认生成「平均好看」的脸；「好看」「清冷」这类模糊词把控制权交回了模型；要求完美对称、无瑕，本身就是平均脸。办法是把变量从形容词换成骨相和瑕疵。

**顺序：骨相 → 五官 → 气质**，不要从气质词开始。

- 每个说话的角色挑一个和其他主角都不同的脸型方向（女：清冷 / 明艳 / 温润 / 英气 / 敦厚；男：文雅 / 硬朗 / 锋锐 / 亲和 / 沧桑），两个主角不能落在同一类。
- 每张脸一个**身份锚点**，精确到毫米和左右（右眼下 2 mm 一颗淡痣、左眉尾一道浅旧痕、下颌 1 mm 的不对称）。锚点每个项目单独设计，不复用模板里的。
- 每张脸加**受控瑕疵**：看得见的毛孔、轻微不均的肤色、浅细纹、轻微不对称。禁止写磨皮、完美对称、无瑕。

**脸部描述块**（整块复制使用，不要拆开）：

```
[性别] 一位女性，东方女性面孔
[骨相] 脸型 + 颧骨外扩程度 + 下颌角（度数）+ 下巴
[五官] 眼型 / 双眼皮宽度 mm / 眼尾角度；眉形；鼻（山根 / 鼻头）；唇形 + 唇色
[妆容] ……（男性写 [面部]：眉形、胡茬 / 下颌青影）
[发型] ……
[识别] 右眼下 2 mm 一颗极淡小痣；左眉尾 3 mm 一道浅旧痕
[气质] 冷/暖 × 锐/钝，一行
[镜头] 正面半身，面部朝向镜头，目光平视      ← 保留，否则模型爱给忧郁侧脸
[姿态] 双手不入画，不触碰面部               ← 保留，否则手会搭到脸上
[光] ……
[画风] 写实，保留皮肤纹理与毛孔，不磨皮
```

男性另外写上解剖特征，免得越画越女性化：眉骨突出、下颌角分明、鼻梁宽平一些、下巴略方、喉结明显、肩宽。

[骨相][五官][识别] 是身份层，永远不改；[气质] 半固定；[光][画风] 是唯一可以换的开关。每次换风格之后，先检查锚点（痣、疤）还在不在、在不在原来那一侧。

**锁脸三步**：

1. **定妆图**：脸部描述块 + 场景光 + 情绪，每个角色出 3–4 张，挑一张。
2. **四视图**：用定妆图出一张 16:9 的四格：正面、四分之三侧、侧面、背面，全身，同一站姿，浅灰渐变背景，柔光，锚点每格都在。哪一格老是出错，回头把定妆图的服装写细，不要反复重抽四视图。
3. **镜头里只用锚点句**：不要每个镜头重写 200 字的描述（那等于每个镜头重新抽一次脸）。把每个人物压成约 60 字的锚点句，原样复制进每个镜头的提示词，只改场景和动作；定妆图和四视图一起作为参考图。

另外：seed 管不住跨场景的脸（seed 决定的是整张图的噪声），只在同一场戏里重抽时有用。参考图强度是个旋钮：太强，脸锁住了但不听提示词；太弱，听提示词但脸会散。

## ③ 场景空镜和道具图

**场景图**：每个场景、每个反打机位一张空景。

- 每个场景定 3–4 个有名字的锚点（比如：主位 · 长老席 · 殿门 · 香炉），写进场景图，也写进这个场景的每个镜头，反打机位才不会跑到另一个房间。
- **光源列清并封闭**：「Lighting: desk candles and cold window light, no other source.」同一句话贴进这个场景的每张关键帧和每条视频提示词，模型就少了重新打光、重画背景的余地。
- 写明天气状态（雨多大、湿还是干）和必须一直在的道具。
- 排除东西用名词：「no altar, no prayer mats」，不要堆形容词。
- 群众背对镜头或在暗处：「all other patrons seen from behind or in silhouette, none facing camera」。画面里少几张多余的脸，模型就少几张会漂、会重复、会换人的脸。
- 用场景图做参考的关键帧都加一句「保持原场景图中的光影色调」。

**道具图**：凡是要拍特写或推动剧情的道具（手机、戒指、合同），各出一张参考图：中性背景，正面和四分之三侧，旁边放一只手比出真实大小。道具上的文字（手机界面、文件内容）后期用程序做或合成，不要指望图像模型写对。

## ④ 分镜和状态板

**站位图**：每场戏先画一张俯视站位图：谁在画左、谁在画右，180° 轴线在哪，机位能放在哪一侧。这场戏的每个镜头都守这一侧。对话时说话的人看向画外的对方，不看镜头（手机自拍、监控这类画面除外）。

**状态板**：每场戏一张表，每一拍一行：

| 拍 | 位置（相对场景锚点、在画面哪侧） | 姿势 | 每只手拿着什么 | 头发 | 干湿 | 伤/脏 | 道具在哪 | 光源开关 | 声音状态 |
|---|---|---|---|---|---|---|---|---|---|

- 每张关键帧的提示词原样复制它那一行。
- 状态的每次变化都要由某一拍的动作造成：没有人在画面外被淋湿、被铐上、换了位置。
- 也可以让图像模型画成一张图：俯视站位图标好每拍的编号，旁边配同样编号的小缩略图。
- 头发、湿度、警灯这些「顺手就漂」的状态，以前全是渲完才发现的。有了状态板，看关键帧和看成片都对着它查，不只对比相邻镜头。

关键的拍子可以先让图像模型出一张 2×2 的机位图（同一拍、四个完全不同的机位），只用来挑 1–2 个机位，再按挑中的机位重画正式关键帧。四格图分辨率低、头发会漂，不能直接当首帧。

## ⑤ 关键帧

每个镜头在分镜表里标一种：

- **FIRST（默认）**：只给首帧，结束状态用文字写在提示词里（「ends with her hand already on the rail」）。用文字写结束状态，动作通常能做完；首尾帧一起给，中间的动作反而常常做不完。
- **FIRST + LAST**：只在两种情况下给尾帧：下一个镜头要从这个镜头的结尾接（接力、动作剪辑点），或者结尾构图必须精确落位（运镜终点、揭示画面、海报帧）。尾帧和下一镜的首帧按状态板的同一行画，剪辑点两边才对得上。
- **SPLIT**：两步以上的动作（伸手 → 抓住 → 拉）拆成两个镜头，在动作中间切，每个镜头只做一步。不要指望一对首尾帧把中间的多步动作补出来。

**接力**（用上一条的末帧当下一条的首帧）最多连续 2 次。再往后人会变样，要回到定妆图重画一张干净的关键帧。取末帧：

```bash
ffmpeg -sseof -0.15 -i shot_a.mp4 -frames:v 1 -update 1 shot_a_last.png
```

**每张首帧在用之前都要看。** 镜头会精确地从首帧开始，首帧里多一个人、少一个道具、位置不对，两个 seed 都会带着这个错。看人数、多出来的动物和道具、时间（白天/夜晚）、季节、左右位置。左右要看实际出的图：作者遇到过人物左右和提示词写的正好相反。

图像模型出的 16:9 图（比如 1672×941）要变成 1344×768 时，比例 1.777 比 1.75 宽，应该裁掉左右两边；裁上下会出黑边。

## ⑥ 动画样片（用户和自己的检查点）

把关键帧按台词时间线排起来，配上临时配音（TTS 或自己念）、底噪和屏幕字，剪成静帧样片。故事、节奏、衔接在这里判断，要改就改分镜和图，不改视频。

## ⑦ 出片

只有审过的关键帧才送去渲。

| 镜头类型 | 用什么 | 片长 | seed |
|---|---|---|---|
| 无对白：动作、氛围、空镜、插入镜头 | i2v（首帧，可加尾帧） | 4.5–12 s | 1 个；空镜 2 个 |
| 对白、一场戏 | r2v（首帧 + 定妆参考 + 声音参考） | 5–12 s | 2 个，挑好的 |

```bash
python3 tools/h3.py submit --kind i2v --image kf/s03.png --prompt-file prompts/s03.txt --secs 8 --seed 11 --out shots/s03_a.mp4
python3 tools/h3.py submit --kind i2v --image kf/s03.png --prompt-file prompts/s03.txt --secs 8 --seed 12 --out shots/s03_b.mp4
python3 tools/h3.py wait <id1> <id2>
```

- 先一次性把整批任务交上去，再等；渲染的同时做下一批的关键帧和质检。
- **渲长、剪短**：最短渲 4.5 s，剪辑时再切短。几句挨着的短台词合成一段，用 `[Shot N]` 分镜，不要每句单独渲。
- 按内容定长度，不要超过 12 s。每条的最后半秒常常有形变，剪掉。

## ⑧ 质检

每条出片先过 `take_gate.py`，再看联系表：

```bash
python3 tools/take_gate.py shots/s03_a.mp4                                 # 无对白
python3 tools/take_gate.py shots/seg01_a.mp4 --profile dialogue --lines "台词一" "台词二" \
    --yunet face_detection_yunet_2023mar.onnx                                # 对白
bash tools/contact_sheet.sh shots/s03_a.mp4
```

`take_gate` 的判定：

| 结果 | 含义 | 怎么办 |
|---|---|---|
| FAIL：CUT 没有 ≥ 2 s 的完整镜头 | 模型自己切得太碎 | 换 seed 重渲 |
| FAIL：FREEZE | 画面冻结 ≥ 1 s | 换 seed 重渲 |
| FAIL：LINE 没说出来或说错 | 召回 < 0.6（按拼音比对，同音字不算错） | 换 seed 重渲 |
| WARN：CUT 碎片 / 台词中间被切 | 模型自切留下 < 1 s 的碎片，或切在一句台词中间 | 剪辑时避开 |
| WARN：EXTRA | 多出台词以外的人声 | 剪掉，或用 gate 只保留台词时段 |
| WARN：ZOOM | 画面持续推拉，也可能只是人物走向镜头 | 在三个时间点抽帧，看背景地标有没有变大 |
| WARN：LENS | 说台词时接近正脸，可能在直视镜头 | 看画面确认 |

联系表上逐帧看：

- 动作链的每一环有没有按顺序出现；
- 有没有多出来的人、换了手的道具、服装漂移、机位移动；
- 画面下三分之一有没有烧进去的字；
- 最后一秒有没有形变。

一条镜头的毛病常在中段冒出来，只看最后一帧会漏，在大约 30% / 65% / 95% 处各抽一帧看。FAIL 的镜头不进成片。

## ⑨ 剪辑、配乐、字幕

- **在模型自己的切点上剪**，`take_gate` 报出的 `pieces` 就是可用片段。不要留下 < 1 s 的另一个镜头的碎片。
- **i2v 的第一秒最慢**（从静帧起步），不要从片头取，取动作最强的那一段。
- **看着顺比镜头多重要**：平均镜头 ≥ 3.5 s；除了最多两个刻意的冲击镜头，不要有 < 1.5 s 的镜头。一个连续镜头能撑住的台词就不要切。
- **每个剪辑点都要有理由**：动作、视线、反应、插入镜头、时间跳跃或声音。剪辑点两边的位置、朝向、手和道具、姿势要对得上，检查每个剪辑点的前后两帧；对不上就换素材、删镜头（台词可以压在插入镜头上当画外音）或重渲。
- **同机位只放大一点点就是跳切**：同一条镜头里前后两段要么连成一整段，要么中间插一个反应或别的机位，要么景别变化 ≥ 1.3 倍。不要用 ffmpeg 的 `zoompan` 做推镜头，它按整像素步进，会一抽一抽的。需要的特写去渲，不要从中景裁。
- **声音带画面**：J-cut（下一句台词先在上个画面下响起）和 L-cut 让剪辑点有动机；电话铃在接电话那个镜头之前就响。
- **音画同步**：每一段素材都要有一条和画面等长的音轨（静音段也要放等长的静音）。时长按整帧取整，用 concat 滤镜拼接，不要用 concat demuxer 加 `-c copy`。每条视频链最后都加 `setsar=1`，否则不同 SAR 的片段拼不起来。
- **字幕用剧本原文**，时间取 whisper 的逐字时间，不要直接用识别出来的文字（会写成同音错字）。
- **配乐**：整片一条底乐，对白段压低而不是撤掉；情绪片用一首连续的器乐。你听不到的时候不要替别人选曲，出几个版本让人用耳朵挑。

## ⑩ 发布

- **AI 生成标识**：每条公开的 AI 视频都要带（MiniMax H3 许可附件 A 第 12 条，以及国内的 AI 生成内容标识规定）。《古代监控实录》竖屏版已经把「内容由AI生成 · 纯属虚构演绎」烧进画面。
- **音乐**：用发布平台曲库里的音乐，在发布时加；有版权的歌只做内部预览。
- 不用真人的脸和声音，不仿冒真实的剧名和人物。
- 封面用分拍表里选好的那张「海报帧」；钩子文字不要盖住脸和眼睛，缩到约 200 px 宽的缩略图还要能看清。
