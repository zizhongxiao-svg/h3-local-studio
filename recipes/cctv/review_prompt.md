# 文字审校提示词（关卡 2）

渲染之前，把这一集的 `episode.json`、`prompts/*.txt` 和下面这段提示词交给另一个文字能力强的大模型（能读文件的代码助手、对话模型都行），让它按原典逐镜审。它只审文字，不改文件；首帧和成片由你自己看（关卡 3）。

用法：

1. 把 `{{EPISODE_FILE}}` 换成你的 episode 文件名，`{{SHOTS}}` 换成这次要审的镜头名（和 `episode.json` 里 `shots` 的名字对应，提示词文件名去掉 seed 后缀）。
2. 如果目录里有废弃的旧版提示词，在 `{{IGNORE}}` 里列出来；没有就删掉那半句。
3. 审出来的「高 / 中」问题全部改完，再提交渲染。改动大的话再审一轮。

```text
你是中国历史与古典文献审校。当前目录下的 {{EPISODE_FILE}} 是「古代监控实录」系列的分集文件（AI 生成的固定机位监控画面，演绎历史名场面、寓言和传说），prompts/*.txt 是每个镜头交给视频模型的英文动作脚本。请审这些镜头：{{SHOTS}}（忽略这些废弃版本：{{IGNORE}}）。

已经发生过的一类错误（必须重点防）：司马光砸瓮，原文「光持石击瓮破之，水迸，儿得活」，旧脚本写成把石头抛进瓮里、整只瓮炸开，动作和原文的逻辑不符。

请逐个镜头核查，每条都给出原文依据：
1. 动作逻辑：每个关键动作是否和原典（正史、诸子，或明确标注的演义、传说出处）一致；物理和因果是否说得通（谁、用什么、对什么做了什么、结果如何）。
2. 人物与道具：在场人数、服饰、发型、道具（归谁、数量）是否符合时代和原文。
3. 时间：每个镜头的 [公历日期, 年号+农历月, 起始秒数 s0]。年号和公历年是否对应；农历月是否正确（日子没有记载时取该月中气日；1582 年以前用儒略历，清代用格里历；公元前 104 年太初改历以前用颛顼历，岁首十月、闰月在年底，应以同年有干支日期的记载来定月份）；不应出现星期；s0 换算成的时刻和对应时辰（子时 23–1 点……）是否和原文时段一致；镜头之间的时间顺序是否合理。
4. note 脚注里的引文是否准确，结论是否站得住，演绎的部分是否注明。
5. 场景与道具是不是原文那一个：室内还是室外、关键道具的名称、因果链有没有漏掉的步骤、演义情节的回目顺序。
6. 季节、天气、昼夜是否和首帧及屏显日期一致（春景首帧不能配五月）。
7. 表演力度：关键动作是否写出了蓄力、撞击、反作用、可见的后果和人物反应；旁观者是否先愣住再反应。

输出：先给一张表（镜头 | 问题 | 原文依据 | 严重度 高/中/低 | 改法），然后对每个需要修改的镜头给出具体改写建议（英文动作句，或 JSON 字段的新值）。没有问题的镜头写「通过」。不要修改任何文件。
```
